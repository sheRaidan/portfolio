Run Buddy

The Run Buddy is an exploration of how physical & digital elements come together to create an engaging, holistic experience. It made use of the P5 JavaScript library to create the digital aspects, and a Makey Makey kit for the physical components.

Run Buddy’s key theme is teaching kids heart health; using a cute character, bright visuals, and sound to retain attention.

Process

There are two parts to the Run Buddy: the Buddy & board, and the website.

Paper prototype

The physical components took a few iterations in order to ensure sizing was optimal for not only fitting the electronics, but made sense for a children’s toy. I stuck to simple geometry not only for the ease of production, but also because many kids’ games use low-poly character designs. I also opted to only build a section of track to keep components proportional.

Assembly process

Track board

The site was admittedly simpler to design; my idea was clearer and the P5 library made programming intuitive. The two key aspects I needed to include were a visual indicator of how far the Run Buddy had “run” and its heartbeat.

I made a track design using simple geometry that I could then use to place the tracker. This helped because I could use sine & cosine functions to place the tracker around bends. I tried to keep the physical track section and the digital track looking as similar as possible to build the connection between the two. As a bonus, I included a sound effect for every three laps completed.

In the end, I made the heartbeat reader an overlay that can be toggled by touching the Run Buddy’s heart (holding spacebar). This overlay shows the heartrate in BPM, plays a beating sound effect in rhythm with the rate, and turns the screen more red the higher the rate.
